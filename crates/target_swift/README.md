# Swift Code Generation Target

This target generates idiomatic Swift code from JSON Typedef schemas.

## Features

- ✅ **Basic types**: `Bool`, `Int8`/`UInt8`/`Int16`/etc., `Float`/`Double`, `String`, `Date`
- ✅ **Collections**: Arrays `[T]` and dictionaries `[String: T]`  
- ✅ **Optionals**: Native Swift optional support with `T?`
- ✅ **Structs**: With `Codable` conformance and proper `CodingKeys`
- ✅ **Enums**: String-based enums with `CaseIterable`
- ✅ **Type aliases**: Using Swift `typealias`
- ⚠️ **Discriminated unions**: Basic support (needs testing)

## Usage

```bash
jtd-codegen schema.jtd.json --swift-out output/
```

## Generated Code Example

```swift
// Code generated by jtd-codegen for Swift v0.2.1

import Foundation

public struct User: Codable {
    public let favoriteNumbers: [Double]
    public let isAdmin: Bool
    public let name: String

    private enum CodingKeys: String, CodingKey {
        case favoriteNumbers
        case isAdmin
        case name
    }
}
```
